# TooCreate — Agency Website

A premium, interactive single-page site for **TooCreate**, a full-service content & creator agency.

## Hosting on GitHub Pages

This is a fully static site — no build step required.

1. Create a repository and push these files:
   - `index.html`
   - `styles.css`
   - `script.js`
2. In your repo, go to **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **Deploy from a branch**.
4. Select your branch (e.g. `main`) and the `/ (root)` folder, then **Save**.
5. Your site goes live at `https://<username>.github.io/<repo>/`.

All asset paths are relative and the only external dependency is Google Fonts (loaded over HTTPS), so it works on Pages with no extra config.

## Features
- Bold orange-red / chartreuse brand system with the looping "navigate" motif
- Animated stat counters, scroll reveals, sticky nav, marquees, FAQ accordion, mobile menu
- Fully responsive, reduced-motion friendly, keyboard-accessible
